# 200슨피단 신호 대시보드

원작자(아기티큐) **26.08.14 최종판** 룰을 그대로 구현한 신호 사이트입니다.
GitHub에 올리면 **매일 정오(한국시간)에 자동으로 갱신**되고, 신호가 바뀌면 텔레그램으로 알려줍니다.

전부 무료입니다. 서버도, API 키도 필요 없습니다.

## 구현된 룰

| 항목 | 값 |
|---|---|
| 기준 지표 | S&P500 순수지수(^GSPC) 종가 + 200일 이동평균 |
| 밴드 | ±3% |
| 진입 | 상단 +3% 돌파 → 3일 분할, TQQQ 67% · SPYM 33% |
| 탈출 | 하단 −3% 이탈 → TQQQ·SPYM 전량 매도 후 SGOV |
| 소익절 | +10 / 25 / 50% → TQQQ 잔고의 10%를 SPYM으로 |
| 대익절 | +100 / 200 / 400% → TQQQ 잔고의 50%를 SPYM으로 |
| 방어 브레이크(TS) | **SPX** 고점 대비 −10%마다 TQQQ 50%를 SPYM으로 (다회성) |
| 리밸런싱 | 상승장 중 밴드 안 첫 재진입 시 1회 67/33 재조정 |
| 적립식 | 밴드 위=SPYM 100% · 안=TQQQ 67/SPYM 33 · 아래=SGOV 100% |

설정 화면에서 26.08.12판(밴드 ±2.5% / TS는 TQQQ −25% / 진입 TQQQ 100%)으로 전환해 비교할 수 있습니다.

## 신규 진입자 모드

‘내 포지션’이 비어 있으면 화면 맨 위가 **아직 아무것도 안 산 사람 기준**으로 바뀝니다.
기본 신호등은 이미 보유 중인 사람에게 하는 말이라("TQQQ 보유 유지" 등) 초심자에게는 오해를 주기 때문입니다.

상황별로 이렇게 안내합니다.

| 지금 상태 | 신규 진입자에게 |
|---|---|
| 사이클 한복판 (돌파 4일 차 이상) | **진입 시점 아님.** SPYM으로 대기하며 다음 사이클을 기다림. 하단 밴드까지 남은 거리를 숫자로 표시 |
| 상단 밴드 돌파 1~3일 차 | **지금이 진입 신호.** 목표 금액의 N/3을 TQQQ 67 · SPYM 33 비중으로 매수 |
| 하단 밴드 아래 | **SGOV 100%로 대기.** 상단 밴드 돌파까지 남은 거리를 표시 |

평단가와 수량을 입력하면 자동으로 일반 모드로 돌아갑니다.

## 포지션 입력 두 가지 방식

**직접 입력** (기본) — 평단가·수량·SPYM·SGOV를 손으로 넣습니다.

**매매 기록으로 계산** — 거래를 하나씩 남기면 잔고가 자동으로 계산됩니다. 입력칸은 잠기고, 기록을 추가하거나 지울 때마다 즉시 다시 계산됩니다.

| 구분 | 돈의 흐름 | 필요한 값 |
|---|---|---|
| 매수 | SGOV → TQQQ | 단가 + 수량 |
| 소익절 / 대익절 / TS / 리밸런싱 | TQQQ → SPYM | 단가 + 수량 |
| SPYM 매수 | SGOV → SPYM | 금액 |
| 현금 입금 | → SGOV | 금액 |
| 전량 탈출 | 전부 → SGOV | TQQQ 청산 단가 |

평단가는 **이동평균법**으로 계산합니다. 매도해도 평단가는 그대로고, 전량 매도하면 0으로 초기화됩니다.

기록이 앞뒤가 안 맞으면 빨간 경고가 뜹니다 — 보유 수량보다 많이 판 경우, 입금 없이 매수해서 현금이 마이너스가 된 경우 등.

> 사이클 도중에 뛰어들면 상승분은 이미 지나갔고 하락 위험은 그대로 떠안게 됩니다. 이 전략의 수익 대부분은 사이클 초입에 들어가 추세를 끝까지 타는 데서 나오므로, 기다리는 것 자체가 전략의 일부입니다. 원작자도 댓글에서 신규 진입자에게 SPYM·SGOV 대기를 권했습니다.

# 배포하기 (30분)

## 1단계 — GitHub 저장소 만들기

1. https://github.com 로그인 → 우측 상단 **+** → **New repository**
2. Repository name: `200sunpi` (아무 이름이나 가능)
3. **Public** 선택 ← 중요. Private은 GitHub Pages가 유료입니다
4. 아래 **Add a README file** 등 체크박스는 **전부 비워두세요** (빈 저장소로 시작하는 게 파일 올리기가 편합니다)
5. **Create repository**

## 2단계 — 파일 올리기

저장소 메인 화면(Code 탭)에서 **Add file** 버튼 → **Upload files**.

주소창에 직접 쳐도 됩니다 — 어떤 상황에서도 동작하는 경로입니다:

```
https://github.com/내아이디/저장소이름/upload/main
```

> 저장소를 막 만든 직후 화면에 보이는 **uploading an existing file** 링크를 눌러도 같은 곳으로 갑니다.
> 다만 저장소를 만들 때 ‘Add a README file’에 체크했다면 그 링크가 있는 화면이 아예 나오지 않습니다.
> 위의 **Add file → Upload files** 경로를 쓰세요.

여기에 `index.html`, `data.json`, `state.json`, `README.md`를 끌어다 놓고 **Commit changes**.

### scripts 폴더

`scripts/update.py`도 같은 화면에서 `scripts` 폴더째 끌어다 놓으면 됩니다.

### .github 폴더 (드래그로는 잘 안 됩니다)

점(.)으로 시작하는 폴더는 탐색기에서 숨겨져 있어 드래그가 실패하기 쉽습니다.
이건 **직접 만드는 편이 확실합니다**:

1. 저장소에서 **Add file** → **Create new file**
2. 파일명 칸에 아래를 **그대로** 입력 (`/`를 칠 때마다 폴더가 자동 생성됩니다)

```
.github/workflows/update.yml
```

3. 아래 편집창에 `update.yml` 내용을 붙여넣고 **Commit changes**

> macOS Finder에서 숨김 폴더를 보려면 `Cmd + Shift + .` 을 누르세요.

### 다 올렸는지 확인

저장소 Code 탭에 이렇게 보이면 됩니다.

```
.github/workflows/update.yml
scripts/update.py
data.json
index.html
README.md
state.json
```

## 3단계 — Actions 권한 켜기

저장소 **Settings → Actions → General** → 맨 아래 **Workflow permissions**
→ **Read and write permissions** 선택 → **Save**

이걸 안 하면 자동 갱신 결과를 저장하지 못합니다.

## 4단계 — 첫 실행

저장소 상단 **Actions** 탭 → 좌측 **200슨피단 신호 갱신** →
우측 **Run workflow** 버튼 → 초록 **Run workflow**

1~2분 뒤 초록 체크가 뜨고 `data.json`이 생성됩니다.
실행 로그를 열면 오늘 신호가 한 줄로 찍혀 있습니다.

## 5단계 — 웹페이지 켜기

**Settings → Pages** → Source: **Deploy from a branch**
→ Branch: **main**, 폴더: **/ (root)** → **Save**

1~2분 뒤 주소가 나옵니다:

```
https://<내아이디>.github.io/200sunpi/
```

폰 홈화면에 추가해두면 앱처럼 씁니다. (사파리 → 공유 → 홈 화면에 추가)

# 텔레그램 알림 (선택, 5분)

신호가 **바뀔 때만** 옵니다. 매일 같은 메시지가 오지 않습니다.

## 봇 만들기

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름과 아이디를 정하면 **토큰**을 줍니다
   (`8123456789:AAF...` 형태. 이게 `TELEGRAM_TOKEN`)
3. 방금 만든 내 봇을 검색해서 **대화 시작 → 아무 메시지나 전송** ← 이걸 해야 봇이 나에게 말을 걸 수 있습니다
4. 브라우저에서 아래 주소를 열어 `chat` 안의 `id` 숫자를 확인 (이게 `TELEGRAM_CHAT_ID`)

```
https://api.telegram.org/bot<내토큰>/getUpdates
```

## GitHub에 등록

저장소 **Settings → Secrets and variables → Actions → New repository secret**

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 위에서 확인한 숫자 |

두 개를 등록한 뒤 Actions에서 한 번 더 **Run workflow**를 돌리면 첫 메시지가 옵니다.

# 알아둘 것

**갱신 시각** — 매주 화~토 한국시간 정오에 돕니다(UTC 03:00). 미국장 마감 후 충분히 지난 시각이라 종가가 확정돼 있습니다. 미국 공휴일에는 새 데이터가 없어 커밋 없이 지나갑니다. 시간을 바꾸려면 `update.yml`의 `cron` 값을 고치세요.

**판정은 확정 종가 기준입니다.** 장중 가격으로 신호를 바꾸지 않습니다. 원작자도 "실시간 주가면 잘못된 신호라 느린 게 차라리 낫다"고 밝힌 부분입니다.

**내 포지션과 매매 기록은 브라우저에만 저장됩니다.** 서버로 전송되지 않고, GitHub에도 올라가지 않습니다. 대신 브라우저 데이터를 지우면 사라지니, 설정의 **백업** 버튼으로 JSON을 가끔 내려받아 두세요. 기기를 바꾸면 새로 입력해야 합니다.

**상태 머신은 15년치를 매일 처음부터 다시 돌립니다.** 그래서 중간 상태를 저장해둘 필요가 없고, 데이터가 수정돼도 결과가 어긋나지 않습니다. 다만 데이터 맨 앞(2012년 무렵)에서 시작 상태를 `BELOW`로 가정하므로 그 시점에 진입 이벤트 하나가 실제와 다르게 잡힐 수 있습니다. 이후 사이클이 여러 번 완결되므로 현재 신호에는 영향이 없습니다.

**야후 API가 막히면** `update.py`가 4번까지 재시도합니다. 그래도 실패하면 Actions가 빨간 X로 표시되고 `data.json`은 이전 값이 유지됩니다. 대체 소스로 Stooq(`https://stooq.com/q/d/l/?s=^spx&i=d`)를 붙일 수 있습니다.
